# VaultFolio

A responsive executive single-page portfolio application built with React, Vite, and Tailwind CSS. Configured for GitHub Pages deployment.

## Prerequisites
- **Node.js**: >= 22.0.0
- **npm**: v10+

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
